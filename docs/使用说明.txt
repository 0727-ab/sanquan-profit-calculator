三全利润与人工测算器 V1.1
==========================

怎么打开
  双击「三全利润与人工测算器.html」，会用 Chrome 或 Edge 打开。不用安装，断网也能用。

日常怎么用
  1. 利润测算：选商品，改黄色格子（售价、销量、成本），右边立刻出利润、图表和一句结论。
  2. 促销试算：点「基准 → 复制到促销」，再只改折扣和销量。
  3. 人工成本：在「人工成本」页选预设 A / B / C 再改数字，
     给每个商品填「分摊比例」（团队月人工里算到这个商品的比例），
     点「用人工表」后，利润会按人工表计算（含绩效、提成、阶梯激励）。
     想看不含人工的结果，在利润页「人工」下拉框选「不计人工」，人工表设置会保留。
  4. 自己加费用：展开「进阶」，点「新增一项」，选性质和计法；金额可直接填，也可写公式，如 =30/60*0.8
  5. 导出 Excel：右上角「导出 Excel」。导出的表格带公式，在 Excel 里改黄色格子会自动重算。

数据保存
  · 数据自动保存在这台电脑的浏览器里，关掉再打开还在。
  · 换电脑或发给同事：点「保存方案」存成 .json 文件，对方点「打开方案」。

文件
  三全利润与人工测算器.html   计算器本体（只需要这一个文件）
  示例导出.xlsx               用演示数据导出的 Excel，看看导出效果
  使用说明.txt                本文件

注意
  演示数据全部为假设。请换成采购单、结算单上的实际数字，并取消「估计值」勾选。
